# 食費と冷蔵庫（アプリ版）

ホーム画面に追加すると、ブラウザの枠なしで全画面のアプリとして起動します。
AI機能（レシート読み取り・アドバイス・献立・アシスタント）は Gemini API を使います。

## 公開のしかた（GitHub Pages の例）

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべてそのまま置いて push する
2. リポジトリの Settings → Pages で、Branch を `main`、フォルダを `/ (root)` にして保存する
3. 数分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` をスマホで開く

HTTPSで配信できる静的ホスティング（Cloudflare Pages、Netlify など）なら、どこでも動きます。

## ホーム画面への追加

- iPhone（Safari）：共有ボタン →「ホーム画面に追加」
- Android（Chrome）：右上の「︙」→「ホーム画面に追加」（または「アプリをインストール」）

## AIの設定

1. Google AI Studio で Gemini の APIキーを発行する
2. アプリの 設定 → AI（Gemini）にキーを入れ、「接続を確認してモデル一覧を取得」を押す
3. 保存する

キーはその端末の中（ブラウザの保存領域）だけに保存され、ファイルやサーバーには含まれません。

## データ

- データはその端末の中に保存されます。端末を変えるときや念のための保存には、設定の「バックアップを書き出す」「バックアップを読み込む」を使ってください
- claude.ai 版のデータも、claude.ai 版の設定で「バックアップを書き出す」（コピーされます）→ アプリ版で「バックアップを読み込む」に貼り付け、で移せます
